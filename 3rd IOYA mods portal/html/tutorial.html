IOYA SMP INSTALLATION GUIDE

One setup.
Zero confusion.

Everything you need to get Minecraft ready and join IOYA SMP. Follow the steps in order. You'll be playing with the gang soon.

THE PROCESS · 01—05

Follow the steps.

01

Get the required files

Start by downloading the IOYA SMP modpack and the required installation files.

  • Download the IOYA SMP modpack.
  • Download any additional required files listed on the Downloads page.
  • Keep the files somewhere easy to find, like your Downloads folder.
02

Prepare your Minecraft launcher

Open your Minecraft launcher and make sure you're using the Minecraft version required by IOYA SMP.

  • Launch your Minecraft launcher.
  • Check your Minecraft version.
  • Make sure it matches the version mentioned on the Downloads page.

Important: Minecraft versions matter. Different versions may not be compatible with the same mods or server.

03

Install Fabric

IOYA SMP uses Fabric mods. You need the correct Fabric Loader installed for your Minecraft version.

  • Open the Fabric installer.
  • Select the correct Minecraft version.
  • Keep the installation settings correct.
  • Install the Fabric profile.
04

Install the mods

Place the required mod files inside your Minecraft mods folder.

  • Open your Minecraft game directory.
  • Find the mods folder.
  • If it doesn't exist, create a folder named mods.
  • Move the downloaded mod files into it.

Don't unzip individual mod JAR files. Mods usually need to remain as .jar files inside the mods folder.

05

Launch & join IOYA SMP

You're almost done. Start Minecraft using your Fabric installation.

  • Select your Fabric profile.
  • Launch the game.
  • Open Multiplayer.
  • Add the IOYA SMP server using the server address provided by Shin.
  • Join and start playing.

You're in. Welcome to IOYA SMP.

Missing some files?

Head back to the Downloads page to get the required modpack and installation files.
